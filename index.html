03
Core Projects

实战项目

六条长期推进的能力线：从风格训练到 Agent 编排，每一项都要能落回商业产出的标准里。

01

装饰画风格 LoRA 训练

以装饰画品类为起点，训练风格化 LoRA 把画风固化下来，让同一风格能稳定、可复现地批量产出，而不是每次重新试运气。

LoRA 训练数据集清洗风格固化
02

电商模特场景图智能生成

把模特与场景分开管控再合成：人物姿态、服装、光位各自可调，一次设定的场景可以复用到整季的产品主图上。

人像 + 场景批量合成主图规范
03

多智能体内容创作 Agent

按"策划 → 生成 → 审校 → 交付"拆分角色，把提示词与质检规则写进 Agent 流程，减少人工在环节之间的搬运。

Agent 编排提示词工程自动审校
04

AI 视频生成与剪辑管线

图像成果向动态延伸：关键帧生成、图生视频、自动剪辑与配乐串成一条管线，让同一套视觉资产能同时供给图文与视频场景。

图生视频自动剪辑素材复用
05

品牌视觉风格模型微调

为品牌做专属模型微调，把配色、质感、构图习惯固化进模型，让不同人执行也能产出同一套视觉语言。

模型微调品牌一致性可交付规范
06

AIGC 增效融合工作流

把 AI 环节嵌回原有的设计流程而不是另起一套：素材进出、命名、归档、质检都对上团队既有习惯，AI 才真正被用起来。

ComfyUI 节点流程嵌入质检标准
